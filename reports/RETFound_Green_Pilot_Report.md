# RETFound-Green 前測報告
**糖尿病視網膜病變五級分類、跨資料集表現與低標註優化**

2026-11-19｜醫學影像期末專題

## 摘要

本次前測以 RETFound-Green v0.1 抽取眼底影像特徵，再以 APTOS 已標註影像建立 5-NN 參考集，評估 APTOS 內部與 IDRiD 外部的 DR 0–4 級分類。APTOS 80/20 切分的 Macro-F1 為 **55.50%（APTOS）與 27.36%（IDRiD）**。改為 70/30 後，分別為 **55.75%（含新增影像的 APTOS 測試集）與 26.71%（同一批 IDRiD 影像）**。固定測試影像比較時，縮小參考集只使兩組 Macro-F1 各下降不到 1 個百分點，但兩組測試之間的落差仍大。前測顯示原始特徵可支援來源域分類，搭配這套 5-NN 規則的外部五級分類仍偏弱。

## 1. 原始模型的限制與解法

| 問題 | 本次處理 |
|---|---|
| 官方公開的 `retfoundgreen_statedict.pth` 是特徵抽取用 checkpoint。官方範例以 `num_classes=0`、平均池化產生 384 維特徵，該介面沒有已訓練的五級 DR 分類頭。 | 凍結權重，以來源域 APTOS 的已標註影像作參考。查詢影像與參考影像的向量做 L2 正規化，再以 cosine 相似度取五個鄰居等權投票。原始權重直接分級的 Accuracy、Macro-F1 仍列 N/A。 |
| 推論輸入須與發布範例相容。 | 讀圖轉 RGB、校正 EXIF 方向，雙線性縮放至 392 × 392 並啟用抗鋸齒，像素轉為浮點並縮放至 [0,1]，各通道用 mean = 0.5、std = 0.5 正規化。先驗證小批形狀 `[6, 3, 392, 392] → [6, 384]`，再抽取 3,607 張影像的特徵。 |
| k-NN 票數或相似度可能相同。 | 相似度相同時依參考影像 ID 升冪排序，投票平手由平手類別中最相近的鄰居決定。兩個測試集共用同一 APTOS 參考集與同一規則。 |
| 重複照片與衝突標註可能影響切分。 | APTOS 官方有標註的 3,662 張排除 96 張同級重複影像，另隔離 62 張像素相同但標註衝突的影像，剩餘 3,504 張。參考與測試之間未發現完全相同的解碼 RGB 像素。 |

前測的 k-NN 使用 APTOS 標籤做下游分級，無須更新編碼器權重。原論文亦使用凍結特徵上的 logistic regression（linear probing, LP）進行下游分類，可作下一步的對照。 [官方權重與推論說明][official] · [RETFound-Green 原論文][paper]

## 3. 泛化能力分析

1. **本次 5-NN 系統的跨資料集五級泛化偏弱。** 80/20 的內外部 Macro-F1 落差為 **28.14 個百分點**。70/30 固定以原 APTOS 700 張比較，落差為 **28.00 個百分點**。兩個參考集規模下都觀察到相似的落差。APTOS 的高 Accuracy 主要來自 DR 0 和 DR 2 的表現，DR 3 和 DR 4 的 Recall 在兩次內部測試皆低於 30%。
2. **外部錯誤集中在特定級別。** IDRiD 的 DR 3 在兩次皆有 14／19 被判為 DR 2，DR 4 皆有 9／13 被判為 DR 2。兩次皆無 IDRiD 影像被預測為 DR 3。鄰近級別難以區分、來源參考集的類別分布、或來源與外部的影像和標註差異，都是可驗證的假設。DR 1 兩次皆為 0／5，樣本數小，單張結果就會改變該級 Recall 20 個百分點。
3. **少 351 張參考影像，固定測試組的點估計變動有限。** 原 700 張 APTOS 的 Macro-F1 從 55.50% 降至 54.72%（以未四捨五入數值計算，下降 0.79 個百分點）。同一批 IDRiD 從 27.36% 降至 26.71%，下降 0.65 個百分點。擴大後 APTOS 測試集的 55.75% 同時反映參考與測試組成的改變。僅比較兩個仍有數千張標註參考的單次切分，尚無法推論少量標註時的學習曲線。
4. **結論的適用範圍是 APTOS → IDRiD 的前測。** 目前分數把特徵、5-NN 和來源資料組成的影響疊在一起。兩資料集的類別比例、成像條件與標註程序等因素均可能影響結果，這份前測無法分離各因素。官方 CSV 缺乏可靠的病人 ID，查核做到影像 ID 與精確像素，病人層級與預訓練影像逐張重疊仍未獨立驗證。原論文將 IDRiD 用於下游評估，並記載 DDR 全部影像參與預訓練。DDR 因此不適合作為此 checkpoint 的獨立外部證據。 [RETFound-Green 原論文][paper]

## 4. 可優先驗證的優化方向

| 方向 | 對應問題與驗證方式 |
|---|---|
| 凍結特徵＋線性分類頭 | 使用相同低標註子集比較 LP 與 5-NN。若 LP 明顯改善，代表改變下游決策規則就有機會提升結果。 |
| 每級使用同等數量的原型 | 以每級一個 cosine 原型，降低比較時受參考樣本數不均的影響。用相同標註比較 DR 1、3、4 的 Recall，同時觀察 DR 0、2 是否下降。 |
| 只做保守的來源域亮度變化 | 用同一張已標註影像模擬輕微曝光變化，量測特徵的穩定性。需保留原圖並確認亮度變化沒有使病灶不可辨識。若仍不足，可另外測同骨幹的輕量微調或風格增強。MixStyle 可作另一個風格泛化對照。 [MixStyle 論文][mixstyle] |

## 5. 本專題提案：視圖穩定加權的類別原型

**研究假設**　若同一張眼底影像僅經輕微亮度調整，就在某些特徵維度出現較大變動，這些維度可能對曝光較敏感。降低其影響，再讓每級各用一個原型參與比較，有機會用相同的少量標註得到較穩定的外部分級。這是待驗證的設計，靈感來自 few-shot 原型分類。 [Prototypical Networks 論文][proto]

### 方法

1. **以小預算建立 APTOS 參考樣本。** 從固定來源訓練池開始，每級取 5 張，共 25 張。第二個預算每級 10 張，共 50 張，並包含前一組。以既有標籤模擬分層抽樣。若實際部署時標籤未知，找齊各級所需的查閱與標註成本也須計入。
2. **從每張已標註影像產生三個視圖。** 使用原圖與兩個溫和的 gamma 視圖，例如在 [0,1] 像素上採用 0.95、1.05，沿用相同的縮放與正規化。保留病灶位置及畫面範圍。把三個視圖輸入凍結編碼器，分別對 384 維特徵做 L2 正規化。每一張原始影像只計一筆標註，兩個額外視圖只增加來源影像推論。
3. **估計維度穩定性並建立五個原型。** 對每張影像計算同一維度在三個視圖的變異，再先按級平均、最後對五級等權平均，得每維變異 $v_j$。以中位數尺度 $s=\operatorname{median}_j(v_j)+10^{-8}$ 正規化，使用 $w_j=\max(0.5,(1+v_j/s)^{-1/2})$。每張來源影像先平均三個視圖的特徵，再乘上各維權重、重新 L2 正規化。同級特徵取平均並再次正規化，即為該級原型。權重下限保留對亮度敏感但仍可能與病灶有關的訊號。
4. **以原圖推論。** 測試影像只抽一次特徵，套用由 APTOS 計算出的權重並重新正規化，預測 cosine 相似度最高的原型等級。編碼器不需更新，不使用 IDRiD 影像或標註估計權重或選設定。

若少量樣本不足以估計穩定性，或同一等級包含多種差異很大的外觀，單一原型可能拉低分類表現。小幅 gamma 變換只能模擬部分亮度差異，所估權重也可能削弱病灶訊號。下列消融用來判斷應保留哪些步驟。

### 公平比較與標註預算

| 比較組 | 要回答的問題 |
|---|---|
| 5-NN、LP | 改善是否超過同一預算下的前測規則與線性分類頭？ |
| 單視圖 cosine 原型 | 每級一個原型本身是否帶來改善？ |
| 三視圖平均、各維等權的 cosine 原型 | 只使用視圖平均是否已足夠？ |
| 三視圖＋穩定加權 cosine 原型 | 降低不穩定維度的權重是否有額外貢獻？ |

- **固定資料與種子。** 建議沿用原 APTOS 700 張及 IDRiD 103 張做前測對照，另從原 APTOS 參考集一次劃出來源驗證集。所有方法在同預算、同種子共用同一批已標註影像。先做 25、50 張兩個低成本點，若仍有明顯不足，再接上 proposal 的 5%、10%、25%、100% 巢狀預算，並記錄實際總數、各級數與種子 17、42、2026。驗證集與評估集使用的既有標註另列，避免把 25 或 50 張誤解為整個實驗的標註成本。
- **先選最少的可用標註量。** 在 APTOS 驗證集比較三種子平均 Macro-F1。可事先鎖定「距 100% 標註 LP 的來源驗證 Macro-F1 不超過 2 個百分點」作為務實的預算門檻。挑出最早達標的預算，並與同預算 LP 比較。2 個百分點是本專題的提案門檻，後續應在實驗前固定。若沒有任何預算達標，報告各預算的增益和未達標幅度。
- **用外部集檢查代價。** 鎖定方法與預算後，以 IDRiD Macro-F1 為主要外部指標，同時報告 APTOS Macro-F1、QWK、各級 Recall／樣本數及混淆矩陣。看外部絕對分數與 DR 1、3、4 是否改善，並列三種子結果與變異。若要估計差值不確定性，可在同一測試影像上做配對 bootstrap，並註明缺乏病人群組時的限制。
- **區分探索與確認。** 本設計已參考現有 IDRiD 誤判，因此回測同一批 103 張屬探索。正式驗證應使用事先鎖定且尚未用於方法選擇的外部影像，並查核預訓練重疊。以最少標註達到最大改善是優化目標，實際增益必須由學習曲線與消融確認。
